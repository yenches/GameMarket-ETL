# GameMarket-ETL (В разработке)

Платформа спроектирована для ответа на ключевые коммерческие вопросы издателей и инди-разработчиков:

1. **Стратегия запуска (Выбор ниши, Гео и Сезонность):**
   - Какого жанра/сеттинга выпускать игру, чтобы минимизировать конкуренцию и максимизировать ROI?
   - В какие страны инвестировать бюджет локализации (где наибольшая покупательская способность)?
   - В какое время года (и в какие релизные окна) выходить на рынок, чтобы не попасть под AAA-релизы, но застать пик продаж?

2. **Стратегия монетизации и скидок:**
   - Делать ли скидки? Через сколько месяцев после релиза запускать первую распродажу?
   - С какой периодичностью и какой глубины (20%, 35%, 50%) делать скидки для удержания «длинного хвоста» (Long-tail) продаж без выжигания аудитории?

---

## Архитектура данных (Data Pipeline)

В проекте реализована **Medallion Architecture (Bronze -> Silver -> Gold)** поверх S3-совместимого объектного хранилища и реляционной СУБД PostgreSQL. Для обеспечения высокой скорости работы BI-инструментов вся тяжелая логика вынесена на уровень ETL, а Apache Superset работает со строго плоскими, предрассчитанными витринами.
